## Пропозиції

1. Розділення на методи - Монолітний main() розбито на логічні функції
2. Видалення дублювання - cleanText() метод не використовувався, але логіка повторювалась в main()
3. Stream API замість циклів
4. Іменування змінних - distincts → distinctWords, freq → frequencies
5. Константи - Магічне число 30 і шлях до файлу винесені в константу
6. Клас-обгортка для слів - WordFrequency замість додавання радків
7. Форматування виводу - Структурований вивід результатів
8. Видалення мертвого коду - Закоментований Path path і невикористаний cleanText()
9. Документація - коментарі для публічних методів

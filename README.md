## Пропозиції оптимізації

1. Map замість двох окремих масивів - String[] distincts + int[] freq
2. Видалення проміжної конкатенації стрічок - distinctString += word + " "
3. PriorityQueue для top-K замість повного сортування - Тримаємо тільки 30 елементів замість сортування ~5000
4. Явне очищення масиву words після використання - words = null;
5. Додати garbage collector - System.gc();
6. Видалення проміжного масиву з конкатенацією - distincts[i] += " " + freq[i]
7. Фільтрація порожніх слів одразу - if (!word.isEmpty()) не додає порожні ключі в HashMap
8. merge() замість get/put - Одна операція замість двох
9. Видалення методів extractDistinctWords() та calculateFrequencies() з масивами
10. Arrays.sort(words) видалено - Не потрібно сортувати 400k елементів для знаходження унікальних
11. WordFrequency об'єкти тільки для топ-30 - Замість ~5000 об'єктів створюємо максимум 30

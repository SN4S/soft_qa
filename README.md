# Зауваження

1. Назва класу humanIMB не відповідає станадарту (HumanBmi).

2. Назва змінних W, H — неінформативна та не в camelCase(width,height).

3. Поля W та H оголошені як public — порушення інкапсуляції.

4. Поле imb оголошене як static, хоча належить до конкретного об’єкта.

5. У конструкторі значення imb обчислюється як static для всіх об’єктів одразу.

6. Методи takeW, takeH мають некоректну назву (має бути getWidth, getHeight).

7. Методи putW, putH також порушують стандарт назв (має бути setWeight, setHeight).

8. У setter-ах повторюється формула розрахунку IMB — дублювання коду.

9. Метод Result() оголошений як static — але він повинен працювати з об’єктом.

10. Метод Result() порушує Java naming conventions (має бути getResult()).

11. У Result() використано оператор & замість && — логічна помилка.

12. Порядок умов у Result() неправильний (є взаємоперекриття діапазонів, але не else-if).

13. Всі if-и незалежні, замість else if, що створює зайве перевіряння.

14. Немає перевірки на нульову або від’ємну висоту → можливий division by zero.

15. Немає коментарів та жодних пояснень логіки.

16. Клас humanIMB не відповідає принципу SRP — він і зберігає дані, і обчислює.

17. Метод takeImt() нічого не робить корисного через static та неправильну архітектуру.

18. Назва "IMB" — помилка (правильно BMI — Body Mass Index).

19. Метод Result() повертає null, якщо IMB не потрапив у жоден діапазон (погана практика).

20. В main використовується незрозуміла назва змінної humanIMB humanIMB — порушення readability.

21. Всі класи знаходяться в одному файлі.
